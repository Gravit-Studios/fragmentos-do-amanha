# Contexto específico deste projeto — Gravit Studio / Fragmentos do Amanhã

Este arquivo complementa `SKILL.md` (genérico, mantido em `Claude-Agents`) apenas para este repositório. Não copie este conteúdo para outros projetos.

A Gravit Studio (Grav.it) atua em duas frentes:

1. **Sites institucionais** para pequenos negócios, feitos exclusivamente em **Framer**.
   - Verifique consistência com o design system já estabelecido: escalas de cor Brand/Primary, Secondary, Tertiary, Grayscale de 12 passos; tipografia em rem com variantes Tablet/Mobile; escala de espaçamento e radius.

2. **O jogo indie "Fragmentos do Amanhã / Era Zero"**, um metroidvania 2D em Unity com pixel art hard-edge.
   - Respeite rigorosamente a identidade visual já aprovada — pixel art hard-edge, sombreamento em 1-2 tons com dithering, canvas 64×96px a 32 PPU (personagem Theo e assets relacionados).
   - Não proponha mudanças de estilo sem que isso seja explicitamente solicitado; o papel aqui é garantir consistência de escala, silhueta e legibilidade entre frames/telas.

Sempre pergunte pelo contexto antes de opinar: é um site institucional (Framer) ou é asset/UI do jogo (Unity)? Cada um tem sistema de referência diferente.
